# Procision · AI 研究工作台

本地运行的 AI 研究工作台：左侧由你整理任务、方向、子进度与结论，右侧在对应目录中继续 Codex CLI 会话。研究记录由你手动维护，终端状态只用于提醒，不会自动修改进度。

当前版本 **1.1.0** 新增独立方向会话、可拖动左右分栏、原位编辑与图片预览，并完善终端提问、复制粘贴、换行和本轮完成提示。完整更新见 [更新记录](CHANGELOG.md)。

## 首次安装

当前启动脚本和终端交互以 Windows 为主要验证环境。需要 Node.js 24 或更新版本；使用 Codex 工作区还需要安装并登录本机 Codex CLI。普通手动记录不需要 Codex。

```powershell
git clone https://github.com/xiaobxj/precision.git
cd precision
npm ci
npm start
```

打开 **http://127.0.0.1:4312**。首次启动自动创建空的本地数据库，仓库不包含个人任务、图片附件或 Codex 会话内容。

## 打开

双击 `启动工作台.cmd`，浏览器会打开 **http://127.0.0.1:4312**。后台服务以隐藏窗口启动，重复打开会复用已有服务。

也可以在本目录运行 `npm start`。运行需要 Node.js 24 及以上；首次安装依赖使用 `npm install`，之后日常打开不需要重新安装。手动进度功能离线可用；Codex 交互使用本机已安装、已登录的 Codex CLI，无需为工作台额外填写 API 密钥。

## Codex 协作工作区

默认打开左右协作视图：左侧编辑任务、方向和子进度，右侧使用 Codex 终端。“思考与结论”默认收起，展开后放在下方，保留两侧操作空间。视图、选中的方向、右栏开关均在当前浏览器中记忆。顶部“手动进度”可切回完整记录视图；窄屏按上下两块展示。

Codex 协作视图隐藏大标题、新建任务横幅和装饰页脚，缩小外边距，并让终端使用更多横向空间和当前窗口高度；大屏不再限制内容最大宽度。“进行中的方向”保留在终端上方。需要创建任务时，切换到“手动进度”，或在终端之外按 `N`。

桌面上可拖动进度区与 Codex 工作区之间的竖向分隔条：向左扩大终端，向右扩大进度区。宽度会在当前浏览器保存，刷新或切换视图后保留；窗口缩小时自动限制宽度，重新放大后恢复偏好。双击分隔条恢复默认；聚焦后可用 `←/→` 微调，`Home/End` 调到两端，拖动中按 `Esc` 取消。终端随布局调整行列数，拖动不会重建连接。

在 Codex 协作视图中，点击左侧任务、方向、子进度或结果的编辑按钮（方向和结果也可点标题），会直接在对应卡片内编辑。右侧终端仍可输入，不出现整页遮罩。点击“保存修改”或在编辑区按 `Ctrl + Enter` 保存；取消或 `Esc` 收起后保留本地草稿，下次打开继续。切换主题或筛选时保留编辑内容。左侧图片按栏宽完整预览，隐藏常驻文件名条，点击图片可放大；原位编辑中粘贴截图同样直接预览。

有任一子进度处于“进行中”，父方向及其任务就显示“进行中”，优先于待跟进和旧的手动状态，并自动进入右侧 Codex 列表。其它方向可以通过 ⠿ 拖到右侧，或点击“在 Codex 中打开”手动加入；固定的入口刷新后保留，可点击“取消固定”移除。拖动和固定不会修改进度、重排方向、启动新的 CLI 或向 AI 发送内容。运行中的终端仍保留收尾入口。

父方向与子方向均可独立绑定目录、会话、历史会话与关键文件。卡片右下角的“在 Codex 中打开”切换到该方向，也支持拖动 ⠿。右侧显示父子路径，进行中的父方向和子方向都自动出现；普通执行项可以只记录进度、不关联会话。已有记录无需迁移。

1. 点击左侧卡片右下角的“在 Codex 中打开”，再点击右侧“关联设置”。填写实际研究目录，也可以从输入框的目录候选中选择。候选来自 `D:/workflow/research/strategies`，只列出目录，不自动猜测方向归属。子方向首次关联时预填父方向的目录和关键文件，会话 ID 留空；可改成自己的子目录，保存后各自独立管理。
2. 已经有会话时，点击“浏览会话”，按标题、目录或 ID 搜索已加载的会话；可继续加载更多，或粘贴完整 UUID。选择会话仅保存绑定，不会启动终端。没有会话时留空，保存目录后点击“新建会话”。
3. 点击“恢复会话”，在网页内使用真实 Codex CLI。新建会话通过官方 App Server 建立并命名，再用 CLI 恢复；创建过程不发送模型请求。终端启动明确指定 session ID 与目录，不使用 `--last`。
4. “相关文件”浏览该方向目录及子目录，可预览文字、图片，固定常用文件或复制完整路径。HTML 以文本显示，不执行；预览限制 1 MB，目录一次显示最多 400 项。目录穿越及指向根目录以外的链接被拒绝；`.git`、`.codex`、`.env` 等不会列出。
5. “记录进度”定位左侧的对应方向。终端输出不会自动写入子进度、结果、思考或任务完成状态。绑定元数据也不会改变原有完成时间。
6. Codex 提问时，先点击终端或右下角“回到底部”，再按 CLI 当前提示回答。已用本机 CLI 0.156.1 的真实提问组件验证：`↑/↓` 选择选项，`Tab` 补充说明，`Enter` 确认，多题可用 `←/→` 切换；中文文字和多题回答均能提交。`Shift+↑`、`Shift+Tab` 等组合键会传给 CLI，具体用途以当前提示为准。“回到底部”会滚到最新输出并聚焦输入，拖动终端滚动条也能到达完整的最后一行。
7. 终端输入中使用 `Shift + Enter` 换行，普通 `Enter` 提交。选中左侧文字并复制后，点击终端，使用 `Ctrl + V`、`Ctrl + Shift + V` 或 `Shift + Insert` 粘贴文字；中文、多行与空行保留，粘贴不会提前提交。快捷键由网页处理，避免 `Ctrl + V` 被 CLI 误认为粘贴图片。
8. 鼠标选中终端文字后，`Ctrl + C` 复制选区，不向 CLI 发送中断信号；只有没有选中文字时，普通 `Ctrl + C` 才传给 CLI。`Ctrl + Shift + C` 始终作为复制快捷键，没有选区时不做操作。复制失败会提示，保留选区，也不会变成中断操作。

### 终端与会话的生命周期

- 网页每约 5 秒只读检查绑定会话最近一轮的保存状态。确认本轮回复完成后，上方方向卡片及终端状态标签变绿，显示“本轮已完成”；下一轮尚未完成、状态读取失败或无法确认时恢复普通颜色。中断、出错、等待回答不算完成。绿色不会修改手动进度，不弹窗、不抢焦点、不重连终端。离开网页期间不主动轮询，回来后更新。
- 状态检查通过 App Server 的 `thread/turns/list`，只请求最新一轮的元数据，不读取回复正文、不恢复会话、不发送模型请求。跨进程不能可靠区分所有运行细节时显示“终端运行中”；CLI 内自行切换会话的限制见下文。此功能涉及后台代码，需在当前研究结束后重启工作台后台启用，仅刷新网页不能给旧后台添加接口能力。
- 切换方向、切换手动视图、收起面板、关闭或刷新网页，均不会停止服务中仍运行的终端。刷新通过 WebSocket 重连，恢复屏幕与有限滚动记录。
- “结束终端”会中断该终端的工作。服务退出或电脑重启后，终端进程不能保留；再次打开后使用“恢复会话”继续已保存的对话。
- 工作台内同一个方向只启动一个终端，同一个会话不能在两个方向同时运行。另一个网页连接时会接管输入，原网页变为只读；可点击“重新连接”接管回来。外部 CLI 窗口是否正在使用同一会话，当前版本不能判断。
- 新建或更换会话会保留旧绑定的历史 ID 和目录。正在运行时，需要先结束终端才能更换目录、会话或删除方向；删除父方向或任务时，也会检查子方向的终端。固定文件不受此限制。
- 为保持方向归属，请使用工作台的“新建会话”和“关联设置”切换会话。直接在 CLI 内使用 `/new`、`/resume` 或 `/fork` 改变会话，当前版本不会自动更新绑定；之后应手动关联新的 ID。
- CLI 使用现有登录和权限配置，目录信任及审批仍在终端内操作。工作台不会跳过这些确认。仅对本次启动关闭 CLI 的版本更新提示，版本更新请在普通终端中单独进行。

### 升级与更换目录

仅更新前端时，刷新网页即可加载新界面；后台模块或依赖发生变化时需要重启服务。重启会停止工作台管理的终端进程并中断正在进行的本轮工作，已保存的 Codex 对话和手动记录仍然保留。请等本轮工作结束并保存未发送文字后再升级，重启后通过“恢复会话”继续。

1. 在网页中导出备份，等当前研究结束后停止这个工作台的后台 Node 服务；只关闭网页不会停止服务。
2. 备份整个 `data/` 文件夹。更新代码时保留它，不要用新下载的空数据覆盖已有记录。
3. 更新代码并运行 `npm ci`，再启动工作台。更换目录时，将原来的完整 `data/` 一起复制到新目录；启动脚本会自动定位所在目录。
4. 确认记录正常后恢复各个方向的 Codex 会话。不同目录下的数据库彼此独立，不会自动同步；目录绑定仍使用原有绝对路径，研究目录移动后需手动更新关联。

可选环境变量：`PRECISION_CODEX_PATH` 指定 CLI 可执行文件；`PRECISION_PROJECTS_ROOT` 指定目录候选的根目录；`PROCISION_DATA_DIR` 指定数据目录；直接使用 `npm start` 时可通过 `PORT` 修改端口。Windows 启动脚本默认使用 4312。网页后端只监听本机，终端控制使用同源检查和每次服务启动生成的连接令牌。不要把该服务直接转发到公网。

## 使用

- **新建任务**：填写标题、说明和所属日期，快捷键 `N`。
- **添加方向**：在大任务下建立并行的小方向。原有进度直接保留为方向，文字、图片、顺序和标识不变。
- **添加子进度**：点击方向操作栏中编辑、删除旁边的小加号 `+`，填写标题并粘贴 AI 回复、工作结果或图片。每个方向可记录多条子进度，直接显示完整记录并保留多行文本；保存快捷键 `Ctrl + Enter`。可以折叠一个方向的子进度列表。
- **记录结果**：点击方向操作栏中小加号旁的文档图标，保存验证结果、AI 输出或阶段结论，支持文字和图片。结果按添加顺序保存在该方向的“结果记录”中，可编辑、搜索、折叠和确认后删除。结果没有完成状态，不计入任务数量或进度完成率，也不会重新打开已完成的任务。删除方向或大任务会一并删除其中的结果记录，确认窗口会提示数量。
- **文字加粗**：任务、方向、子进度、结果、思考记录的标题和正文（包括任务说明及当前结论）均支持选中文字后按 `Ctrl + B`（Mac 为 `⌘ + B`）或点击 **B** 按钮加粗，再次操作取消加粗。也可以先开启加粗再输入。格式随草稿和记录保存，刷新、重新编辑及导出备份后保留；思考记录的历史版本也保留当时的格式。已有文字和图片原样保留。
- **方向折叠**：点击方向标题右侧的箭头，折叠后保留标题和右下角的 Codex 入口；再次点击箭头或标题可展开。刷新后保留折叠状态，搜索或从“需要你关注”定位时会展开相应内容。
- **层级与状态**：界面标出“任务（总体目标）→ 方向 → 子方向”。方向与子方向均可独立关联 Codex 会话，子方向也可只作为执行项记录进度。各层标题旁的状态都可点击，包括尚无方向的大任务。选择“待开始／进行中／待跟进／已完成”只修改该层级的状态，不批量修改下级；任务和方向可选择“跟随方向／子进度汇总”恢复自动管理。菜单标明当前模式，支持方向键、Enter、Esc；保存失败保留原状态。下级完成数和完成率单独统计，不随手动总体状态改变。
- **顺序**：方向和子进度各自通过右下方上下箭头排序；子进度只在所属方向内移动。支持编辑和确认后删除；删除方向时会提示同时删除其中多少条子进度。
- **结果与结论关联**：点击结果旁的“关联思考与结论”，关联已有记录或新建记录；一条记录可关联多个结果。右侧记录和详情显示来源任务、方向与结果，点击会清除任务筛选、展开并定位原始结果。结果下方也能打开关联的思考记录。编辑思考记录时可以增减关联，历史版本保留当时的来源；来源删除后保留名称并显示“来源已删除”，不删除结论。
- **完成任务**：有进行中的下级时，父级始终保持进行中；需先调整下级状态，才能将父级设为其它状态。没有进行中的下级时，自动模式依次判断全部完成、待跟进、已开始但未全部完成、待开始；手动模式保留所选状态。删除最后一条子进度后，自动模式的方向恢复为进行中，手动模式保留所选状态。进度完成率按子进度计算，无子进度的方向计为一项，避免重复计算。
- **每日延续**：日期统一使用北京时间。未完成任务从所属日期开始自动出现在之后的每日视图，不复制任务；完成后只保留在所属日期及截至完成日的每日视图。可在“全部任务”找到所有任务。
- **历史日期**：展示纳入该日期的任务及其**最新进度**，不是历史时刻的状态快照。右侧“最近动态”则显示所选日期实际发生的操作。
- **查找**：按任务或进度文字搜索（快捷键 `/`），也可按完成状态筛选。
- **示例模式**：点“查看示例”体验完整界面。示例改动仅在当前页面内存中，刷新重置，退出即返回正式工作空间。
- **明暗主题**：左下角按钮切换，浏览器会记住选择。
- **分栏与整体滚动**：桌面上，鼠标在中间任务区或右侧思考区内时，滚轮只滚动对应栏；移到顶部、两栏之间或页面空白处时，滚动整个页面。页面右侧也保留整体滚动条。栏内滚到边缘不会带动另一栏或页面，方便固定对照位置。编辑保存、更新进度或切换日期时，会保留当前页面及两栏各自的阅读位置。也可用 Tab 聚焦栏位后，通过方向键或 Page Up / Page Down 滚动。手机和窄屏仍按上下顺序阅读。
- **收起日历栏**：桌面顶部左侧的“收起日历栏”将左侧收成窄导航栏，同时扩大任务区与右侧记录区；思考与结论会优先显示在右侧顶部。点击“展开日历栏”恢复，浏览器会记住选择。
- **点击收放两侧栏**：左侧日历边缘的箭头可单击收起／展开，不必拖动；右栏顶部的“收起右栏”将右侧收成窄条，为任务区腾出空间，点击窄条上的“思考与结论”展开。两侧开关互不影响，刷新后保留选择，展开右栏会恢复本次浏览中的阅读位置。
- **拖动日历栏**：拖动左侧栏右边缘调整宽度；向左拖窄会吸附收起，拖开后恢复展开。双击边缘也可收起/展开。支持平滑过渡，拖动时直接跟随鼠标；系统开启减少动画时遵循该设置。聚焦边缘后可用左右方向键微调，`Home` 收起、`End` 展开到最大宽度。

任务由用户手动记录与确认；浏览 Codex 会话只用于选择归属，不会自动导入 AI 对话或判断任务是否完成。

## 思考与结论

右侧“进度一览”下方新增独立的“思考与结论”卡片。此功能不改变原有任务、日期导航或进度操作。

- 点击卡片右上角 `+`，填写标题和当前结论，可选填思考过程。右侧卡片只展示当前结论全文，保留换行；原始思考过程保存在详情中，不会被删除或替代为结论。收起日历后，新增可用宽度主要分给中间任务区。
- 点击记录标题或“查看详情与编辑”，可打开独立阅读窗口并修改记录。
- 记录长期保留，不受当前日期、任务搜索或完成状态影响；卡片内有独立搜索。
- 可以选择“待验证”或“当前结论”，按自己对这条信息的判断标注。
- 思考正文支持最多 200,000 个字符，结论支持 20,000 个字符；保留换行。
- 编辑会保存修改前的完整历史版本，点开记录底部的“历史版本”可回看。
- 不需要常看的记录可以归档，仍可从“查看归档”打开并恢复。
- 草稿、保存失败提醒、冲突检测、JSON 导出备份与原有任务采用相同机制。新增的 `notes` 字段与旧数据兼容，原任务和进度无需重建。

## 保存与备份

### 图片附件

创建或编辑任务说明、方向、子进度、结果记录、思考记录时，可以在输入框中按 **Ctrl + V** 粘贴截图，也可拖入图片或点击“选择图片”。支持 PNG、JPG、GIF、WebP，单张最多 10 MB，每条记录最多 20 张。

图片就绪后点击原有保存按钮，与记录一同保存。列表内展示缩略图，点击可看大图或下载。思考记录移除的旧图片仍能在历史版本中查看。

图片原文件保存在同一个本地 SQLite 数据库的 `images` 表中，不依赖外部图床。上传前先在浏览器 IndexedDB 保留草稿，上传失败可重试，刷新后重新打开同一编辑窗口可恢复。上传但未关联记录的图片会保留，不自动清理。

正式任务存放在本目录 `data/procision.sqlite` 中，刷新页面、关闭浏览器和重启服务后仍保留。保存采用 SQLite 事务；多个窗口编辑发生冲突时会提醒刷新后重试，不会静默覆盖。窗口中的未提交表单会保留为当前浏览器草稿。

右上角“导出备份”下载包含任务、方向与子进度的顺序和状态、方向下的结果记录、思考记录、历史版本和操作动态的 JSON 文件。有图片时同时包含 `imageAssets`（图片类型与 Base64 原始数据），而不只是图片链接。每天第一次修改前会自动将之前的状态和当时已有图片备份到 `data/backups/YYYY-MM-DD.json`。

需要完整迁移时，先关闭此工具的 Node 服务，再复制整个 `data` 文件夹（不要只在服务运行中复制 `.sqlite` 主文件）。服务只监听本机 `127.0.0.1`。

GitHub 仓库仅包含程序代码、启动脚本、说明和使用虚构数据的测试。个人任务、思考记录和图片附件保存在本机 `data/` 中；数据库、备份、导出记录、截图、日志及环境配置均已加入 `.gitignore`。首次运行时会自动创建空工作空间。

## 开发和验证

```text
npm install
npm test
npm run test:ui
```

UI 测试默认使用本机 Microsoft Edge；如需 Playwright Chromium，可设置环境变量 `PLAYWRIGHT_CHANNEL=chromium` 并安装对应浏览器。测试使用独立临时数据，不会操作正式 `data` 文件夹。截图在 `test-results/`。

前端使用原生 HTML/CSS/JavaScript 和 xterm.js；后端使用 Node.js HTTP、SQLite、WebSocket 和 node-pty。终端屏幕由服务端 headless xterm 保留，以便网页重连。界面采用深色画布、精细边框、等宽元信息与语义状态色。

`npm test` 包含目录越界、会话绑定、终端重连与数据完整性验证；`npm run test:ui` 包含原有手动记录和新协作视图。测试数据与正式数据库隔离。`node scripts/verify-terminal.mjs` 是显式执行的真实 CLI 验收：在 `.verification/` 建立测试目录，创建测试会话，通过 `/status` 验证输入与刷新重连，结束后归档测试会话；不发送模型请求。该脚本会对自己建立的测试目录确认 CLI 信任提示，不用于任意项目目录。

`node scripts/verify-question-terminal.mjs` 可在隔离会话中检查真实 CLI 提问组件；加上 `--multiline` 可自动验证中文、多行粘贴、空行和 `Shift + Enter`。该测试代理会阻止模型请求，并把报告与截图保存在已忽略的 `.verification/` 中。常规单元和界面测试使用模拟终端，不接管日常研究会话。

接口参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[Codex CLI](https://learn.chatgpt.com/docs/developer-commands?surface=cli)、[xterm.js](https://xtermjs.org/)、[node-pty](https://github.com/microsoft/node-pty)。

`node scripts/verify-question-terminal.mjs` 是显式执行的交互验收脚本：使用独立临时工作台和测试会话，通过本地协议代理向真实 CLI 注入 `item/tool/requestUserInput`，校验选项、文字与多题回答；代理禁止模型回合和命令执行请求。标准输入接受 JSON 操作（`ask`、`key`、`type`、`resize`、`bottom`、`screen`、`close`），退出时归档测试会话。该脚本不会连接正式工作台的运行中终端。

加上 `--multiline` 可自动验证左侧选中文字后 `Ctrl + C / Ctrl + V` 粘贴到真实 CLI，再用 `Shift + Enter` 添加换行和空行；仅在按普通 `Enter` 后捕获完整输入。提交请求由本地测试代理截获，不发送模型请求。截图与结果保存在 `.verification/multiline-terminal-*`。
