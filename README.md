# Procision · 每日工作台

用于跟踪与 AI 协作的任务：大任务下建立并行方向，每个方向下按顺序记录子进度。

## 打开

双击 `启动工作台.cmd`，浏览器会打开 **http://127.0.0.1:4311**。后台服务以隐藏窗口启动，重复打开会复用已有服务。

也可以在本目录运行 `npm start`。运行需要 Node.js 24 及以上；日常使用不需要安装 npm 依赖，也不需要联网或 AI API 密钥。

## 使用

- **新建任务**：填写标题、说明和所属日期，快捷键 `N`。
- **添加方向**：在大任务下建立并行的小方向。原有进度直接保留为方向，文字、图片、顺序和标识不变。
- **添加子进度**：点击方向操作栏中编辑、删除旁边的小加号 `+`，填写标题并粘贴 AI 回复、工作结果或图片。每个方向可记录多条子进度，直接显示完整记录并保留多行文本；保存快捷键 `Ctrl + Enter`。可以折叠一个方向的子进度列表。
- **记录结果**：点击方向操作栏中小加号旁的文档图标，保存验证结果、AI 输出或阶段结论，支持文字和图片。结果按添加顺序保存在该方向的“结果记录”中，可编辑、搜索、折叠和确认后删除。结果没有完成状态，不计入任务数量或进度完成率，也不会重新打开已完成的任务。删除方向或大任务会一并删除其中的结果记录，确认窗口会提示数量。
- **文字加粗**：任务、方向、子进度、结果、思考记录的标题和正文（包括任务说明及当前结论）均支持选中文字后按 `Ctrl + B`（Mac 为 `⌘ + B`）或点击 **B** 按钮加粗，再次操作取消加粗。也可以先开启加粗再输入。格式随草稿和记录保存，刷新、重新编辑及导出备份后保留；思考记录的历史版本也保留当时的格式。已有文字和图片原样保留。
- **方向折叠**：点击方向标题右侧的箭头，折叠后只显示标题；再次点击箭头或标题可展开。刷新后保留折叠状态，搜索或从“需要你关注”定位时会展开相应内容。
- **状态**：直接点击方向或子进度标题旁的状态标签，选择“待开始／进行中／待跟进／已完成”即可保存，无需进入编辑窗口。菜单会勾选当前状态，支持方向键选择、Enter 确认、Esc 取消；点击子进度序号仍可快速完成。有子进度的方向标注“自动”，点击状态标签即可选择子进度并直接修改其状态：全部完成才完成，有待跟进则显示待跟进。保存失败时保留原状态。
- **顺序**：方向和子进度各自通过右下方上下箭头排序；子进度只在所属方向内移动。支持编辑和确认后删除；删除方向时会提示同时删除其中多少条子进度。
- **完成任务**：所有方向完成时，任务自动完成。新增未完成子进度或撤销完成，会重新打开所属方向和任务。删除最后一条子进度后，方向恢复为进行中，可手动设置状态。没有方向的任务可以手动完成。进度完成率按子进度计算，无子进度的方向计为一项，避免重复计算。
- **每日延续**：日期统一使用北京时间。未完成任务从所属日期开始自动出现在之后的每日视图，不复制任务；完成后只保留在所属日期及截至完成日的每日视图。可在“全部任务”找到所有任务。
- **历史日期**：展示纳入该日期的任务及其**最新进度**，不是历史时刻的状态快照。右侧“最近动态”则显示所选日期实际发生的操作。
- **查找**：按任务或进度文字搜索（快捷键 `/`），也可按完成状态筛选。
- **示例模式**：点“查看示例”体验完整界面。示例改动仅在当前页面内存中，刷新重置，退出即返回正式工作空间。
- **明暗主题**：左下角按钮切换，浏览器会记住选择。
- **分栏与整体滚动**：桌面上，鼠标在中间任务区或右侧思考区内时，滚轮只滚动对应栏；移到顶部、两栏之间或页面空白处时，滚动整个页面。页面右侧也保留整体滚动条。栏内滚到边缘不会带动另一栏或页面，方便固定对照位置。编辑保存、更新进度或切换日期时，会保留当前页面及两栏各自的阅读位置。也可用 Tab 聚焦栏位后，通过方向键或 Page Up / Page Down 滚动。手机和窄屏仍按上下顺序阅读。
- **收起日历栏**：桌面顶部左侧的“收起日历栏”将左侧收成窄导航栏，同时扩大任务区与右侧记录区；思考与结论会优先显示在右侧顶部。点击“展开日历栏”恢复，浏览器会记住选择。
- **点击收放两侧栏**：左侧日历边缘的箭头可单击收起／展开，不必拖动；右栏顶部的“收起右栏”将右侧收成窄条，为任务区腾出空间，点击窄条上的“思考与结论”展开。两侧开关互不影响，刷新后保留选择，展开右栏会恢复本次浏览中的阅读位置。
- **拖动日历栏**：拖动左侧栏右边缘调整宽度；向左拖窄会吸附收起，拖开后恢复展开。双击边缘也可收起/展开。支持平滑过渡，拖动时直接跟随鼠标；系统开启减少动画时遵循该设置。聚焦边缘后可用左右方向键微调，`Home` 收起、`End` 展开到最大宽度。

任务由用户手动记录与确认；当前版本不会自动读取其他 AI 对话或判断任务是否完成。

## 思考与结论

右侧“进度一览”下方新增独立的“思考与结论”卡片。此功能不改变原有任务、日期导航或进度操作。

- 点击卡片右上角 `+`，填写标题和当前结论，可选填思考过程。右侧卡片只展示当前结论全文，保留换行；原始思考过程保存在详情中，不会被删除或替代为结论。收起日历后，新增可用宽度主要分给中间任务区。
- 点击记录标题或“查看详情与编辑”，可打开独立阅读窗口并修改记录。
- 记录长期保留，不受当前日期、任务搜索或完成状态影响；卡片内有独立搜索。
- 可以选择“待验证”或“当前结论”，按自己对这条信息的判断标注。
- 思考正文支持最多 200,000 个字符，结论支持 20,000 个字符；保留换行。
- 编辑会保存修改前的完整历史版本，点开记录底部的“历史版本”可回看。
- 不需要常看的记录可以归档，仍可从“查看归档”打开并恢复。
- 草稿、保存失败提醒、冲突检测、JSON 导出备份与原有任务采用相同机制。新增的 `notes` 字段与旧数据兼容，原任务和进度无需重建。

## 保存与备份

### 图片附件

创建或编辑任务说明、方向、子进度、结果记录、思考记录时，可以在输入框中按 **Ctrl + V** 粘贴截图，也可拖入图片或点击“选择图片”。支持 PNG、JPG、GIF、WebP，单张最多 10 MB，每条记录最多 20 张。

图片就绪后点击原有保存按钮，与记录一同保存。列表内展示缩略图，点击可看大图或下载。思考记录移除的旧图片仍能在历史版本中查看。

图片原文件保存在同一个本地 SQLite 数据库的 `images` 表中，不依赖外部图床。上传前先在浏览器 IndexedDB 保留草稿，上传失败可重试，刷新后重新打开同一编辑窗口可恢复。上传但未关联记录的图片会保留，不自动清理。

正式任务存放在本目录 `data/procision.sqlite` 中，刷新页面、关闭浏览器和重启服务后仍保留。保存采用 SQLite 事务；多个窗口编辑发生冲突时会提醒刷新后重试，不会静默覆盖。窗口中的未提交表单会保留为当前浏览器草稿。

右上角“导出备份”下载包含任务、方向与子进度的顺序和状态、方向下的结果记录、思考记录、历史版本和操作动态的 JSON 文件。有图片时同时包含 `imageAssets`（图片类型与 Base64 原始数据），而不只是图片链接。每天第一次修改前会自动将之前的状态和当时已有图片备份到 `data/backups/YYYY-MM-DD.json`。

需要完整迁移时，先关闭此工具的 Node 服务，再复制整个 `data` 文件夹（不要只在服务运行中复制 `.sqlite` 主文件）。服务只监听本机 `127.0.0.1`。

GitHub 仓库仅包含程序代码、启动脚本、说明和使用虚构数据的测试。个人任务、思考记录和图片附件保存在本机 `data/` 中；数据库、备份、导出记录、截图、日志及环境配置均已加入 `.gitignore`。首次运行时会自动创建空工作空间。

## 开发和验证

```text
npm install
npm test
npm run test:ui
```

UI 测试默认使用本机 Microsoft Edge；如需 Playwright Chromium，可设置环境变量 `PLAYWRIGHT_CHANNEL=chromium` 并安装对应浏览器。测试使用独立临时数据，不会操作正式 `data` 文件夹。截图在 `test-results/`。

前端使用原生 HTML/CSS/JavaScript；服务使用 Node.js HTTP 与 SQLite，无运行时第三方依赖。界面采用深色画布、精细边框、等宽元信息与语义状态色。
